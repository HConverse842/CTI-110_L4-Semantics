Overview

Deadlock is a strategy based MOBA that requires constant analysis of various elements in the game.
Some important elements that you must focus on are listed below:
  1. Enemy Player Locations
  2. Map Events
    • The Rift
    • Midboss
    • The Soul Urn
  3. Enemy Player Upgrades and Characters (Wide Variety of Characters)

Details

Outside of the various side objectives across the map, there are main objectives that are required to win the game.
The order of the objectives is as such: Guardian -> Walker -> Base Guardian -> Base Shrines -> The Patron

MOBA (Multiplayer Online Battle Arena)

What is a MOBA?

A MOBA is a game where two teams compete against each other in a combat style game, utilizing abilities
and upgrades to complete the objective. This requires strong teamwork to effectively win the game. This
requires good communication and coordination.

Deadlock Competitive Ranking

Deadlock has a very good rank system, making players have to play and learn characters before attempting ranked
This is done by creating a list of requirements:

  • Win 15 Games with with 3 different characters (45 games)
  • Have 60 total standard match wins
This prevents players from causing major problems in ranked and also fixes the matchmaking problems
The game had previously.
